# Dordoi Cinema

Учебный сайт кинотеатра в Dordoi Plaza, Бишкек. Афиша, расписание, страницы фильмов, выбор мест и демо-билеты. React, Vite, Lucide и qrcode.react.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Сайт открывается по адресу http://127.0.0.1:5173. Команда `npm run build` собирает сайт в `dist`, а `npm run preview` открывает сборку локально. Относительные пути позволяют разместить её в корне домена или в подпапке.

## Данные и билеты

Сайт неофициальный. Оплата, бронирование и связь с кассой отсутствуют. Расписание и цены взяты из снимка афиши на 8 и 9 октября 2026 года. Схема зала, VIP-места и занятость кресел условные.

Демо-билеты сохраняются в localStorage. Контакты из формы не сохраняются и не передаются. QR-код содержит демо-метку и не подходит для входа в кинотеатр.

Изображения принадлежат их правообладателям. URL источников сохранены в `src/data.js`.

## Проверки

При запущенном локальном сайте:

```sh
npm test
npm run test:journey
```

Проверки проходят путь от выбора фильма до билета: даты, поиск, фильтры, цены, стандартные и VIP-места, ограничения выбора, форма и сохранение. Адаптация проверяется на ширинах 320, 390, 768 и 1440 px.

Нужен Google Chrome на Windows. Проверки используют отдельный временный профиль. Адрес сайта и папка снимков задаются переменными `CINEMA_TEST_URL` и `CINEMA_SCREENSHOTS`.
